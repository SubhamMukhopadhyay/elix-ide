# Changelog

All notable changes to **Elix IDE** are documented here.

## [1.0.0] - 2026-09-24

### Added
- **Core Shell**: Electron 34 + React 18 + TypeScript + Vite + Tailwind CSS obsidian luxury dark theme.
- **Universal Execution Layer**: Execution provider abstraction with local runner, cloud warm sandbox fallback, and network-aware online/local/offline states.
- **Category-First Home**: Quick start across 14 development categories, customizable categories, and instant project templates.
- **Professional Editor**: Multi-tab Monaco editor with breadcrumbs, minimap, split-view web preview, and Expo-like mobile device simulator with QR code generator.
- **Bottom Panel**: Real interactive PowerShell terminal tabs, live execution output with process metrics and timestamps, problems inspection, and ports manager.
- **AI Coding Agent**: Dedicated right-hand panel with permission levels, multi-step planning, before/after visual diff reviews, and Practice Mentor modes.
- **Practice & Career Hub**: Question Bank across DSA, Problem Solving, and Core CS with personalized goal tracking separate from the question bank, embedded code evaluator, and level engine.
- **Hackathons Sprint Hub**: Sprint task boards, team management, countdown timers, and milestones.
- **Career Dashboard**: 28-day streak heatmap, skill matrix, and 1-click resume bullet point export.
- **Project Time Machine**: Automated and manual workspace snapshots with 1-click rollback.
- **Windows Packaging**: Self-contained executable distribution at `release/Elix-IDE-win32-x64/Elix IDE.exe` and 1-click desktop installer script.
